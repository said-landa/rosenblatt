## Decision

Begin the next learning experience with a complete functional Machine. Investigate
its subsystems and descend only as deeply as needed to explain how it works.
Reverse engineering supplies the direction of inquiry; reconstruction, operation
and causal changes can still demonstrate the explanation. A universal particle
foundation is no longer a mandatory opening or prerequisite for this direction.

The creator recalls the mouse as useful prior work but explicitly asks to choose
a different Machine through focused questions. No replacement Machine or exact
variant is selected by this request. Reference Padlock 01 remains the separate
native-engine reference under 0005, not an automatic choice for this new opening.

The creator wants direct participation in code and fine implementation details.
Invite that participation through small changes and focused walkthroughs, while
continuing to own routine enabling engineering. The earlier division of work
must not be used to exclude the creator from programming.

Implement a temporary cold-launch introduction lasting about two to three seconds,
then reveal the regular app. Returning from the background must not replay it.
The creator subsequently approved the quiet wordmark on a dark background and
fade. That approval establishes the visual direction; physical timing, typography
and device behavior still need review.

The creator explicitly authorizes committing and pushing the accumulated source
changes to GitHub and requests instructions for personally delivering future
TestFlight builds. This is session authorization, not a permanent auto-push rule.
No TestFlight upload is requested in this cycle.

## Why now

The creator reports difficulty narrowing the intended experience and wants to
shape it through concrete choices and visible, fine-grained progress. Starting
at constituent scale before choosing the functional question no longer matches
the requested learning sequence.

## Alternatives considered

- Continue the mandatory foundation-first opening: superseded for this direction.
- Immediately restore the mouse as the first Course: contradicts the request to
  choose a different Machine.
- Select and implement a new Course without creator input: would displace the
  requested authorship and invite another mismatch.
- Implement the explicit introduction, preserve prior studies, and ask for the
  next Machine: selected bounded step.
