# 0005 — Select Reference Padlock 01

- Status: Accepted
- Date: 2026-09-07
- Decided by: Creator
- Supersedes: [Decision 0004](0004-select-w1-pin-tumbler-reference-course.md)

## Decision

The first reference Machine is `Reference Padlock 01`, an original Machines
design representing the familiar keyed padlock archetype without copying or
displaying a commercial brand or product.

Its selected functional architecture is a solid rectangular body, captive
U-shaped shackle, four-pin pin-tumbler cylinder, plug-driven cam, and two
locking balls that engage both shackle legs. It must become one coherent,
versioned Machine Variant rather than an undocumented average of products.

The Course teaches through assembly and causal change, not prerequisite
reading. Placing each Component changes what the partial Machine permits,
blocks, or moves. The learner surface has no default instructional text,
labels, progress copy, or textual feedback. Camera, composition, light,
motion, direct manipulation, constraint, sound, and haptics carry the journey.
Text or voice may appear only after deliberate tutor invocation; tutor work is
deferred.

The W1 cylinder Course and text-heavy two-dimensional preview remain a bounded
engineering spike. They are not the accepted Machine, Course, interface, or
representation direction.

## Why now

Creator inspection established that Generation 0 began at the wrong level: it
selected only the cylinder, skipped the complete padlock, and embedded an
unaccepted explanatory sequence in a textual schematic interface. Interface
polish cannot repair that upstream error.

The complete padlock supplies a visible causal journey from empty structure to
a system that can constrain and release its shackle. Building it can itself
produce understanding without inserting a textbook between learner and
Machine.

## Alternatives considered

### Continue the W1 cylinder Course

Rejected as the current direction because it omits the padlock's visible output
mechanism and begins with explanation instead of construction.

### Copy one commercial padlock

Rejected as the primary design. Commercial examples remain evidence and
contrast sources, not learner-facing identity or geometric authority.

### Define an unspecified generic padlock

Rejected. A vague category cannot support stable Components, dimensions,
interfaces, assembly, or reproducible geometry.

## Consequences

- `machine.reference-padlock-01` is the primary Machine identity.
- Work returns to exact mechanical structure and assembly sequencing.
- The component census is a functional hypothesis, not a manufacturing bill of
  materials.
- The first 3D increment contains the body and shackle and must prove camera,
  depth, selection, constrained motion, insertion, and state change.
- Canonical 3D authority is a Machines-owned parametric recipe; imported CAD
  and meshes may be evidence or derived representations.
- Internal authoring tools expose parameters, evidence, uncertainty, and
  diagnostics even though the learner surface does not.
- Existing compiler/runtime code is reused only where complete-Machine evidence
  justifies it.

## Evidence and uncertainty

This is a creator-selected original design, not a claim that all commercial
padlocks use these parts. Exact dimensions, materials, retention, opening bias,
cam and ball geometry, tolerances, and manufacturable assembly remain open.

## Reversibility and revisit triggers

Revisit the architecture if mechanical modeling shows that the selected
subsystems cannot coexist coherently or if a simpler architecture preserves
the same assembly and causal depth.

## Resulting next action

Build the minimum native 3D assembly bench for body and shackle. Use its visual
and interaction evidence to define the next Component and assembly step.
