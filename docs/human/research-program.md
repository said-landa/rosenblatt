# Long-Term Research Program

> Detailed counterpart: [LLM research program](../llm/research-program.md)

Machines is both a product and a long-lived research program. Research exists
to change decisions, improve learning, and discover durable abstractions.

## Ten connected programs

| Program | Central concern |
| --- | --- |
| Machine ontology and semantic expression | How to represent what a machine is and how its parts cooperate. |
| Evidence and machine knowledge | How claims remain traceable, scoped, contested, and revisable. |
| Learning and course design | How construction produces transferable understanding. |
| Semantic geometry and representation | How visual and interactive forms preserve educational meaning. |
| Native runtime and interaction | How the engine executes machine and learning semantics directly. |
| Pedagogical intelligence | How the tutor becomes grounded, distinctive, measurable, and project-controlled. |
| Learner understanding and evaluation | How to infer cautiously from observable reasoning and behavior. |
| Course Factory and authoring | How excellent courses can be produced repeatedly without semantic fragmentation. |
| Compilation, validation, and evolution | How exact revisions remain executable, testable, and migratable. |
| Institutional memory | How evidence, decisions, failures, and methods survive across decades. |

## Reference-course generations

1. **Generation 0:** complete low-fidelity course and observed walkthroughs.
2. **Generation 1:** minimum native vertical research system.
3. **Generation 2:** complete high-quality reference course.
4. **Generation 3:** deliberately different second course that attacks the
   first abstractions.
5. **Later generations:** evidence-backed expansion and replacement of weak
   boundaries.

## Research discipline

Exploratory findings can create hypotheses. They become contracts, policies,
or invariants only after appropriate evidence, comparison, review, and declared
uncertainty.

## Current research question

Which first machine and exact variant can produce the strongest evidence across
the pipeline while remaining small enough to study completely?
