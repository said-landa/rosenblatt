# Machine-First Rosenblatt

> [Engineering counterpart](../llm/machine-first.md) · [Decision 0011](../decisions/0011-machine-first-investigation-and-code-collaboration.md)

Start with a functioning Machine. Ask how it produces its result, enter the
relevant subsystem, and go deeper when that explanation needs it. The stopping
point is a useful causal explanation, not automatically particles. Operating,
disassembling and reconstructing can each help expose that explanation.

We will choose a different Machine from the mouse together. The mouse, foundation
and circuit studies remain available as prior work. No new Machine is selected.

The first small revision adds a quiet Rosenblatt wordmark on a dark screen for
about 2.5 seconds on a cold launch. It fades into the current content and does not
repeat when returning from the background. Reduced Motion removes the fade.
This is an initial visual candidate; device feel remains to be reviewed.

You are invited into the code, including fine details. Work in small changes:
state the intended behavior, inspect the relevant function together, change it,
observe the result, and decide the next detail. Routine engineering remains
handled without requiring your supervision.

Next decision: which Machine are you curious enough about to shape in detail?
Then choose the first observable action we want a learner to explain. A
hand-cranked flashlight is a candidate recommendation, not a selected Course.
