# Machine-First Rosenblatt

> [Engineering counterpart](../llm/machine-first.md) · [Decision 0011](../decisions/0011-machine-first-investigation-and-code-collaboration.md)

Start with a functioning Machine. Ask how it produces its result, enter the
relevant subsystem, and go deeper when that explanation needs it. The stopping
point is a useful causal explanation, not automatically particles. Operating,
disassembling and reconstructing can each help expose that explanation.

The initial focus is electronics. We will choose an electronic Machine other
than the mouse together; the exact device is still open. The mouse, foundation
and circuit studies remain available as prior work.

The opening uses only “Rosenblatt” in white serif lettering on pure black, as
requested on 2026-10-27. Following the 2026-10-28 feedback, its exit fades gently
for 1.6 seconds and the complete opening lasts about 3.5 seconds. The cover stays
in place until the fade finishes. Background return does not repeat it; Reduced
Motion retains a static 2.5-second opening. There is no rose emblem. Physical
appearance remains to be reviewed.

Your selected code workflow is: walk through a small change together, then you
edit. Explain the intended behavior and relevant function before handing over
the edit; inspect the result together. Routine engineering remains handled
without requiring your supervision.

Next decision: which electronic behavior interests you most—sensing, signals,
or computation? Use that choice to select a concrete device and its first
observable action. No complete Course is authored before that selection.
