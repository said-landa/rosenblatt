Rosenblatt should feel like entering, constructing and understanding connected
systems. The foundation serves the machines ahead. The new Lab study makes the
first proposed format available for review; quality acceptance remains open.

| Beat | What is implemented |
| --- | --- |
| Destinations | Procedural 3D glimpses of a phone, satellite, cell and computing hardware introduce the purpose. |
| Ingredients | Named up/down quark symbols have explicit meanings. |
| A composite | A broad assembly preview reveals a simplified proton composition and gluon-mediated binding. Confirming its endpoint records the model review. |
| An atom | An independent electron leads to hydrogen-1. The cloud is one electron’s probability distribution, with zero neutrons in the nucleus. |
| Routes | A shared atomic foundation leads toward electronics, living systems, mechanisms and computing/AI. Future paths are explicitly in development; replay is voluntary. |
| Function | Enter a separate circuit preview, assemble manufactured components and open/close a switch. Current and LED behavior respond to the circuit model. |

The foundation targets roughly 60–90 seconds with voluntary inspection. No
reading countdown or measured learner pacing is claimed. Explanations fade,
can be reopened, and remain available through the scene footnote. Assembly can
be scrubbed, played or completed with a tap; confirmation is separate.

The camera approaches meaningful parts and connections. Touch takes control;
Return to journey restores the authored view. Reduced motion uses cuts. Sound,
pause and mute controls remain absent. The current Lab uses English copy.

The circuit is an explicit scale cut with ready-manufactured components. It is
not a hydrogen-to-phone path and awards no material or Course prerequisites.
Only this electronics preview is playable. The full chemistry, materials,
manufacturing, biology and AI paths still need research and authorship.
